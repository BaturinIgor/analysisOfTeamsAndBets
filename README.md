# Анализатор ставок (Dota 2)

Личный инструмент: матчи Dota 2 сегодня и в эфире, собственная оценка вероятностей, сравнение с линией букмекеров, симулятор бумажных ставок. Ставки система не делает. Требования: [docs/requirements.md](docs/requirements.md).

Сейчас готов **этап 0**: проверка источников данных и начало сбора истории коэффициентов.

## Установка на Mac

```bash
git clone https://github.com/BaturinIgor/analysisOfTeamsAndBets.git
cd analysisOfTeamsAndBets
python3 -m venv .venv
source .venv/bin/activate
pip install -e '.[dev,browser]'
playwright install chromium
cp .env.example .env
```

Откройте `.env` и вставьте токены: `STRATZ_TOKEN`, `ODDSPAPI_API_KEY` (и `TELEGRAM_BOT_TOKEN` — понадобится на этапе 1). Файл `.env` в git не попадает.

## Команды этапа 0

1. **Проверка источников** — по строке на каждый источник, `[ OK ]` или `[FAIL]` с причиной:
   ```bash
   bk check-sources
   ```
   Пришлите вывод в тред: в нём нет ключей, но видно, есть ли BetBoom, Fonbet и Pari в OddsPapi.

2. **Разведка линии BetBoom** — откроется окно браузера на 120 секунд. Перейдите в киберспорт → Dota 2 и откройте 2–3 матча, лучше один из тех, что идут сейчас. Входить в аккаунт не нужно.
   ```bash
   bk betboom-discover
   bk betboom-inspect data/betboom_discovery/<время>   # краткая сводка: сколько кадров и какие команды в них видны
   ```
   BetBoom получает линию через WebSocket бинарными кадрами (protobuf), они сохраняются как `.bin`. Заархивируйте папку и пришлите в тред — по ней будет написан парсер коэффициентов BetBoom.

3. **Коэффициенты BetBoom**
   ```bash
   bk betboom-parse data/betboom_discovery/<время>   # матчи и П1/П2 из записи разведки
   bk odds-add "Team Spirit" "Tundra" --p1 1.85 --p2 1.95       # коэффициенты BetBoom, вписанные вручную перед ставкой
   ```
   Автоматического сбора с сайта BetBoom нет: 2026-11-04 их защита заблокировала IP после работы автоматического браузера. Обходить её не будем — это против правил БК и рискует аккаунтом. Разведку (`betboom-discover`) тоже лучше не запускать.

4. **Основная линия — Fonbet и Pari через OddsPapi.** Один раз определите рынок «победа в матче»:
   ```bash
   bk oddspapi-sample
   ```
   Пришлите вывод в тред — по нему будет прописан `ODDSPAPI_WINNER_MARKET` в `.env`. Сбор в базу — снимок каждые 10 минут в `data/bk.sqlite3`:
   ```bash
   bk collect-odds              # работает, пока открыт терминал
   bk collect-odds --once       # один снимок для проверки
   ```

## OddiWire: автоматическая линия Dota

У OddsPapi на бесплатном тарифе коэффициентов Dota нет. OddiWire отдаёт бесплатно (100 запросов в день, без ключа — демо) линию Oddin.gg, на которой построен BetBoom.

```bash
bk oddiwire-sample
```

Команда покажет инструменты сервиса, найдёт Dota 2 и выведет линию. Ключ, если появится, кладётся в `.env` как `ODDIWIRE_API_KEY`.

Нужен бесплатный ключ (oddiwire.com → Pricing → Free, 100 запросов в день): впишите его в `.env` как `ODDIWIRE_API_KEY`. Демо без ключа — всего 10 запросов за 5 минут на всех пользователей.

Сбор снимков линии (победа в матче, до матча и в эфире; победа на картах — для матчей в эфире) в базу. Сборщик сам растягивает дневную квоту до полуночи UTC (при 100 запросах — примерно раз в 40 минут) и ждёт, если сервис просит подождать:

```bash
bk collect-odds              # оставить работать в отдельном окне Терминала
bk collect-odds --once       # один снимок для проверки
```

В базу пишутся только изменившиеся цены, вместе с вероятностью БК без маржи и пометкой «до матча / в эфире». За снимок уходит 2 запроса плюс 1 на каждый матч в эфире (коэффициенты на карты); `--no-maps` оставляет только 2. `--interval` — минимальная пауза в секундах. Старый источник: `bk collect-odds --source oddspapi`.

## Этап 1: история и рейтинг

```bash
bk sync-matches --days 730     # история про-карт из OpenDota (первый раз ~1–2 часа из-за лимитов; повторно — только новое)
bk rating-eval                 # точность и калибровка рейтинга на последних 180 днях + топ команд
bk predict "Team Spirit" "Tundra" --bo 3   # вероятность серии, честный коэффициент и перевес против Fonbet, Pari и BetBoom (если коэффициенты есть в базе)
```

Пока это только рейтинг Elo по результатам карт Tier 1–2. Форма, патч, состав и драфт добавятся следующими шагами.

## Модель

Вероятность карты считает логистическая регрессия поверх рейтинга Elo. Её признаки: форма за 10 карт и за 30 дней, личные встречи за год, пауза без игр, опыт команды, форма в текущем патче и стабильность состава (замена или стендин её снижают). Составы и патчи загружает `bk sync-matches`: составы идут пакетами через OpenDota Explorer, по 400 карт за запрос. Параметры Elo подбираются, веса обучаются на старых картах, а проверка идёт на последних 180 днях, которых модель при обучении не видела.

```bash
bk model-eval     # точность и калибровка: только рейтинг против модели
```

То же самое показывает команда `/model` в боте. Драфт пока не учитывается.

## Telegram-бот

```bash
bk sync-matches   # один раз (и потом раз в несколько дней): история карт Tier 1–2 для рейтинга
bk bot            # бот + сбор коэффициентов в одном окне; отдельный bk collect-odds тогда не нужен
```

Если в логе «Telegram недоступен: Connection reset by peer» — провайдер режет `api.telegram.org`. Включите VPN на Mac или укажите прокси в `.env`: `TELEGRAM_PROXY=socks5://127.0.0.1:1080` (порт — из настроек вашего VPN/прокси-клиента). После `git pull` переустановите зависимости: `pip install -e '.[dev]'`.

Симулятор бумажных ставок работает внутри `bk bot`. По каждому сигналу бот делает одну бумажную ставку на матч, отдельно для режимов «до матча» и «в эфире», у каждого режима свой банк. Раз в час бот подтягивает новые карты из OpenDota, рассчитывает ставки и присылает уведомления. Итоги смотрите в `/sim`. Настройки задаются в `.env`: `SIM_BANK`, `SIM_STRATEGY` (fixed | percent | kelly), `SIM_STAKE`, `SIM_PERCENT`, `SIM_KELLY`.

Чтобы Mac не засыпал, запускайте бота так: `caffeinate -i bk bot`.

Команды в Telegram: `/today`, `/live`, `/match N`, `/value`, `/team название`, `/settings`. Бот отвечает только ID из `TELEGRAM_ALLOWED_IDS`. Пороги сигнала — `SIGNAL_MIN_EV`, `SIGNAL_MIN_PROB`, `SIGNAL_MIN_ODDS` в `.env`. Команды из линии сопоставляются с историей OpenDota по названию; если команды нет в Tier 1–2, бот честно пишет, что оценки нет.

## Риски: состав и новости

- **Состав.** Бот сравнивает, кто играл за команду в последней карте (или играет в текущем драфте), с основным составом за 60 дней. Если вышел стендин, в `/match` и в уведомлении после драфта появится «⚠️ Spirit: в последней карте играет X вместо Y». Имена игроков подтягиваются при `bk sync-matches`.
- **Новости.** Бот ищет новости за 7 дней по названию команды через Google News RSS (бесплатно, без ключа, на русском и английском). Заголовки со словами «стендин», «замена», «виза», «болезнь», «дисквалификация» помечаются ⚠️. Результат кэшируется на 6 часов. Команда: `/news N` (номер матча из `/today`) или `/news название`.

## Синонимы названий команд

Если команда в линии названа не так, как в OpenDota (переименование, сокращение), у матча не будет нашей оценки. Посмотреть такие команды и похожие названия из истории:

```
bk unmatched
```

Связать названия: `bk alias "Название в линии" "Название в OpenDota"`. Список: `bk alias --list`, удалить: `bk alias "Название в линии" --remove`. Бот подхватывает справочник сразу, без перезапуска. По нему же рассчитываются ставки симулятора.

## Выгрузка в xlsx и CSV

`/export` в боте присылает файл xlsx с тремя листами. На листе «Матчи» текущая линия с нашей вероятностью и EV, на листе «Ставки» все бумажные ставки с CLV, на листе «Итоги» сводка по режимам. Зелёным отмечены выигрыши и положительный EV, красным проигрыши и флаги риска. Файл открывается в Numbers и Excel.

То же из терминала: `bk export` (или `bk export --out ~/Desktop`). Рядом кладутся CSV без цвета. Разделитель «;», кодировка UTF-8 с BOM, чтобы кириллица сразу читалась.

После обновления один раз выполните `pip install -e .`: для xlsx нужна библиотека openpyxl. Без неё будут только CSV.
